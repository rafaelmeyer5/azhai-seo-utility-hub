## What Azhai Is

Azhai is a web-focused suite that puts AI helpers, everyday text utilities, and SEO-oriented checks in one place. It targets anyone who repeatedly edits copy, inspects structured data, builds page metadata, or studies keyword usage.

Rather than bouncing across many one-off sites, you work from a single collection of more than 31 tools. Typical jobs cover measuring length, pretty-printing JSON, assembling meta tags, and measuring keyword density—so the kit fits content prep, on-page optimization, and routine text chores.

## FAQ

### Who should use Azhai?

People who handle text, AI-oriented helpers, JSON structures, and SEO-related content work.

### How do I get the newest build?

Follow [Download Latest Build](https://rafaelmeyer5.github.io/azhai-seo-utility-hub/) near the top of this README.

### Is local use supported?

Yes. Clone the repo, then open or serve the web files on your machine. A static server often gives more predictable results.

### Where do I change tool options?

Inside each utility’s own UI. Normal use does not depend on a documented project-wide settings file.

### A tool misbehaves—what next?

Reload the page, confirm the input suits that utility, and compare against the hosted build or a local static server. If it still fails, open a GitHub issue with browser, input kind, and reproduction steps.

### How do updates arrive?

Through this repository and the hosted build. Watch the repo for recent commits and any release notes.
